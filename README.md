# NanoCore: практикум по анализу .NET-файла

Материалы для демонстрации и самостоятельной лабораторной работы. Исходный исполняемый файл, очищенная сборка, готовая конфигурация и извлечённые плагины в этом репозитории не размещаются. Преподаватель выдаёт учебный образец отдельно в контролируемой среде.

## Материалы

- `student-guide.md` — задания и форма фиксации доказательств.
- `Prepare-StudentLab.ps1` — проверка хеша, подготовка каталогов и инструментов в Windows 11.
- `export_rcdata.py` — экспорт только ресурса RCDATA №1 из PE-файла без запуска образца.
- [Блокнот Colab](https://colab.research.google.com/drive/1Puw7ZSr8N41g3UxRBuRsMJFaAtDVHcfm) (`NanoCore_Config_Decode_Colab.ipynb`) — воспроизведение цепочки расшифрования после ручного исследования кода.

## Порядок работы

1. В изолированной Windows ВМ проверьте хеш образца и откройте его в ILSpy.
2. Сравните исходную и очищенную сборки. Найдите методы чтения ресурса и формирования ключа.
3. Сформулируйте схему преобразований до запуска готового кода.
4. Экспортируйте RCDATA №1 и укажите GUID сборки в блокноте. Блокнот принимает только экспортированный ресурс, не исполняемый PE-файл.
5. Представьте выводы как таблицу «утверждение — метод/строка — наблюдение — ограничение».

Публикация готовых IOC и скриншотов с ответами до защиты снижает смысл задания. Оценка строится по собственным находкам в ILSpy и воспроизводимым доказательствам.

## Подготовка инструментов

Скачайте ILSpy из [официальных выпусков](https://github.com/icsharpcode/ILSpy/releases) и получите проверенную сборку [de4dot](https://github.com/de4dot/de4dot) до отключения сети ВМ. de4dot может загрузить обфусцированную сборку в память для выполнения; запускайте его только в изолированной ВМ со снимком состояния. Скрипт подготовки сам de4dot и образец не запускает.

Для `export_rcdata.py` нужен Python 3 и пакет `pefile`, заранее подготовленный для офлайн-установки. В Colab нужен `pycryptodome`; первая ячейка блокнота устанавливает его отдельно.
